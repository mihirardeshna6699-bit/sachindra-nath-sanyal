Assets
======

sanyal-portrait.jpg
  Archival photograph of Sachindra Nath Sanyal (1893-1942), from the Calcutta
  Mahajati Sadan collection. Published before 1960 and in the public domain in
  India. It is drawn into the gold oval on the Early Life board, cover-cropped
  so it is never stretched and biased slightly upward so the top of the head
  stays in frame.

  To replace it, save your file here as sanyal-portrait.jpg (.jpeg, .png and
  .webp are also tried, in that order). If none is found the board falls back to
  an engraved plate and logs a warning. The mapping lives in PORTRAITS in
  js/main.js and is keyed per subject, so this image is used for Sanyal only.

audio/background.mp3
  Looping background music. Replace this file to change the track - no code
  change is needed. Volume, fades and the M toggle are handled in js/main.js.

Narration
  Not shipped. Each timeline entry has an audioUrl field; point it at a file
  placed in this folder and a "Play narration" button appears on that panel.
